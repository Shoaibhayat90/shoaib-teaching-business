# Shoaib Teaching Business — Tech Education Website

A professional, approachable website for tech education — from computing basics to AI — for kids and adults. Includes a hero section, about, courses and services, student testimonials, and contact.

## Tech stack

- Frontend: React + TypeScript (Vite)
- Backend: Express + tRPC
- Database: Drizzle ORM
